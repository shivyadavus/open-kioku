First win

Install and connect

The setup command indexes the current repository, writes repository-scoped agent guidance and MCP configuration, and checks that the local server responds.

npm install -g open-kioku
ok setup agent cursor --repo . --apply

Use claude for Claude Code; --apply is wired for those two clients. ok mcp install codex|gemini --repo . prints a read-only server entry for the others. Run without --apply to preview; nothing is written.

Core workflow

Plan before editing. Verify after.

01

Build local evidence

ok index . stores symbols, relationships, tests, history, documentation, and optional semantics under .ok/.

02

Compile a plan

ok plan "your task" returns bounded context, impact candidates, validation targets, provenance, and explicit caveats.

03

Verify the change

ok verify --plan plan.json --git (or the verify_change MCP tool) compares the actual changed files with the declared boundary and reports anything outside it.

Measured on four real repositories, re-run nightly.

Holdout split of the commit-derived corpora on the production ok context path. Baselines frozen 2026-09-07 from a hosted Linux runner matrix; the nightly job fails when a watched metric drops more than 0.03 below its baseline.

R@5 — the share of tasks for which at least one file the commit changed is in the first five results.
R@20 — the same within the first twenty results, roughly the whole context pack.
MRR — the average of 1 / rank of the first correct file; 1.0 means it was always first, 0.5 is what you get if the first correct file were always second, or first half the time and never found the rest.
Read it plainly: on a Java repository of about ten thousand files the right file is in the top five about half the time and in the pack about two thirds of the time; on a TypeScript repository of about nine hundred files, in the pack about four in five and in the top five about three in four. Queries are commit subjects, not issue text, so compare a change against the frozen baseline, not the literature. Method, corpora, and scripts ↗
