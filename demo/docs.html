Documentation

Start with evidence. Keep uncertainty visible.

Install Open Kioku, connect your coding agent over local MCP, and use the plan, edit, verify loop on the repository you already have.

First win

Install and connect.

The setup command indexes the current repository, writes repository-scoped agent guidance and MCP configuration, and checks that the local server responds.

Use claude for Claude Code; --apply is wired for those two clients. ok mcp install codex|gemini --repo . prints a read-only server entry for the others. Run without --apply to preview; nothing is written.

npm install -g open-kioku
ok setup agent cursor --repo . --apply

Core workflow

Plan before editing. Check after.

01 · Index

Build local evidence

ok index . stores symbols, relationships, tests and history under .ok/.

02 · Plan

Declare the boundary

ok plan "your task" returns bounded context, impact, validation targets and caveats.

03 · Edit

See what it broke

ok ripple names the calls that no longer fit what the edit changed. It needs no index.

04 · Verify

Check the diff

ok verify --plan plan.json --git compares the changed files with the declared boundary.
