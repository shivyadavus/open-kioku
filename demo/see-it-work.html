See it work

A real commit, stopped halfway.

A commit to Black, the Python formatter, gave one function a new required parameter and updated every caller. We stop that commit halfway, with the function changed and the callers not yet, and ask Open Kioku what is broken. The finished commit is the answer key.

6 of 6call sites it named are lines the real commit went on to change
0.2 sto name them, on a repository of 504 files
0builds, test runs or type checkers involved
26 sfor one recorded Claude Code session to make the change and leave nothing broken
1 · The change

One function gets a required parameter.

Python imports this file without complaint. Each call that still passes one argument fails only when it runs.

src/black/cache.py
-def get_cache_file(mode: Mode) -> Path:
-    return CACHE_DIR / f"cache.{mode.get_cache_key()}.pickle"
+def get_cache_file(mode: Mode, cache_dir: Path) -> Path:
+    return cache_dir / f"cache.{mode.get_cache_key()}.pickle"

psf/black 1ed66a8b33, “Add --cache-dir command-line option” ↗

5 · In Claude Code

With the hooks, the agent hears it right after the edit.

One recorded session on the same repository, before the commit. The prompt asks for the parameter and does not mention callers.

Run it yourself

One script, the same output.

It clones Black into a temporary directory, prints steps one to four, and removes the clone. It needs git, python3 and ok 5.0.0 or later.

npm install -g open-kioku
git clone https://github.com/shivyadavus/open-kioku
open-kioku/scripts/demo-replay.sh

This repository's CI runs the script on every pull request and fails if the output differs from what this page shows.
