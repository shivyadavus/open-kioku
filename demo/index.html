How it works

Three moments in a change, each with something to check.

An agent edits fast and reads little. Open Kioku gives it, and you, a fact to look at before the edit, right after it, and before the merge.

01 · Before the edit

What the task touches, with its evidence

Files, tests and history ranked for the task, each with where the evidence came from and what is missing. The plan declares the edit boundary.

ok plan "change token expiration"
02 · Right after the edit

The calls the change broke elsewhere

Change a signature, rename or remove something, and the sites that no longer fit are named with path, line and reason. No index, no setup.

ok ripple
03 · Before the merge

The real diff against the declared plan

An edit outside the boundary fails the check. In CI, ok gate ci writes the result on the pull request as a Change Dossier.

ok verify --plan plan.json --git
New in 5.0.0

Ripple: what the diff does not show.

A diff shows the function you changed. It does not show the caller in another file that still passes two arguments to a function that now takes three. Ripple lists those callers.

  • Rust, Python, TypeScript, JavaScript, Go, Java and C#, read from the syntax tree.
  • Follows a method call through the type its receiver is declared with, or the type the function it came from returns.
  • In Claude Code the hooks tell the agent right after the edit that caused it, and tell you at the stop what it left.
  • It reads syntax, not types. What it cannot attribute is listed as possible and never counted.

How it decides ↗ · Every number and its method ↗

  • 249 of 250sites it named from half-made changes were then changed by the same commit, on 14 repositories it had never been run on (2,543 commits that change code). One false alarm on their complete commits, now a rule with a test.
  • 5commits on the main branches of widely used libraries that left code naming something they had removed, found across 60 repositories. No false alarm is left on those repositories.
  • 53%of the sites a type checker reports are counted, and 93% are counted or listed, on 835 signature changes checked by Go's type checker, pyright and tsc. Go 78%, TypeScript 34%, Python 37%.
  • 18%is what the first version counted. The comparison is why it now follows a call through the type its receiver is declared with.

What this does not show: that an agent finishes a task better with it. In 40 live sessions on five small tasks, current models fixed every caller or said which they left, with or without the notice.

For any other agent, and for people, ok gate install git --apply puts the same forbidden-path check in a git pre-commit hook.

Local by design

Your repository stays yours.

No hosted index

Search and evidence are stored under the repository's own .ok/ directory. Local semantic search needs no hosted embeddings API.

Read-only by default

The MCP server provides evidence tools; source edits remain in the normal editor and agent workflow.

Network-denial posture

Command execution and model downloads are policy-gated. The default configuration includes network denial, and denial fails closed.

Share proof, not source

ok prove reports index and validation signals and leaves source snippets out. A Change Dossier names sites by path and line, with no source text.

When evidence is missing, the answer says so. A stale index refuses to answer relationship questions instead of guessing from an empty graph. Security model ↗

Start

Two commands, then ask for a plan.

The setup command indexes the repository, writes repository-scoped MCP configuration and guidance, and checks that the local server answers. Run it without --apply to preview; nothing is written.

  • cargo install open-kioku-cli, or cargo binstall for the prebuilt binary.
  • Binaries with checksums, an SBOM and provenance on GitHub releases ↗.
  • Ripple needs none of this: ok ripple works in any git repository.

  1. Install

    npm install -g open-kioku

  2. Connect your agent

    ok setup agent claude --repo . --apply

    Use cursor for Cursor. Codex and Gemini CLI have their own guides.

  3. Plan, edit, verify

    ok plan "change token expiration" --format json > plan.json
ok verify --plan plan.json --git
